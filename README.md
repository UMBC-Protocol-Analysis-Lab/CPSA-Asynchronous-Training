# CPSA Asynchronous Training

Welcome to UMBC PAL!
If you have never seen any CPSA before, this is the place to start.
We have prepared a set of [Lecture Slides](./slides), [Videos](https://youtube.com/playlist?list=PLMKSZInDBosE&si=lQamoCLWi56e4NM2), and [Homeworks](./homeworks/) to teach you how to use CPSA.
If you have questions, please feel free to reach out to one of us over Discord, we are here to help!

**Certificate:** You may be able to earn a certificate if you complete the training to a satisfactory degree.
Earning a certificate will require you to submit all of the homework assignments, and complete a final project and a final exam that we will give to you upon request.

# Homework

The best way to learn a new tool is practice, and watching us write code during the lectures is boring.

You are also free to ask for help in the Discord.

Homework assignments will be posted in the [Homeworks](./homeworks) directory.

# Final Project

There is a final project that will put all of your cybersecurity and CPSA skills to the test, and is a good metric of the kind of work we do in the lab. 
The final project will be given out at the end of the first week, and is to be presnted at the end of the series. 
Details on the final project can be found at the [Final project readme](./final_project/final_project.md).
